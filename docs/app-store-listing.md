# App Store listing (roadmap step 9, 13 November 2026)

Everything to paste into App Store Connect for Toogo's first version, in English (the default for every store) and
Hebrew (the Israel store). Apple's limits are checked: name and subtitle 30 characters, keywords 100 bytes (a Hebrew
letter is 2 bytes, so the Hebrew list is half as long), promotional text 170 characters.

Not checked from here: whether the name is free. App Store Connect says so when you create the app. If "Toogo" is
taken, keep the rest and try "Toogo Japan: Trip Planner".

## Rules followed
- The name, subtitle and keywords are all searched, so no word appears twice across them; each slot adds new words.
- Hebrew search matches whole words, so a word with a prefix (ליפן, לטוקיו) does not match a search for יפן or טוקיו.
  The name keeps ליפן because it reads well; יפן goes into the keywords, and the subtitle uses city names without
  prefixes.
- No competitors' names, no "app", no plurals of words already there, commas without spaces.
- "כשר" is a keyword because people search for it, but the description never says the food is kosher: it says
  "no pork or seafood", which is what the app checks.

**Description**

```
Toogo plans your trip to Japan with the people you travel with.

SWIPE, MATCH, PLAN
• Swipe through more than 1,500 hand-picked places in Japan's main cities and day trips: restaurants, cafés, sights, experiences, shopping and nightlife.

THE WHOLE TRIP IN ONE PLACE
• Bookings: paste or upload a confirmation (email, PDF or screenshot) and Toogo fills in the dates and details.

• Share your plan with a link.

In English and Hebrew.

GOOD TO KNOW
Opening hours and menus change, so check before you go. "No pork or seafood" is not kosher certification.
```

## Category and age rating
- **Primary category:** Travel. **Secondary:** Food & Drink (a large share of the cards are places to eat).
- **Age rating questionnaire:**
  - Alcohol or drug references: infrequent/mild (bars, sake, izakaya). Everything else: none.
  - User-generated content: yes (photos for places). There is moderation: photos are checked before anyone sees them, and there is a report box.
  - Unrestricted web access: no. Links open single pages in an in-app browser.
  - The expected result is 13+. The terms say 18 and over, which is allowed.

## App Privacy (the "nutrition label")

Tracking: **No**. Nothing is shared with data brokers or used for ads. The hotel links name Toogo, not the person.

| Apple's data type | Collected | Linked to the person | Purposes |
|---|---|---|---|
| Contact info: email address | yes | yes | App functionality |
| Contact info: name (the name shown to the group) | yes | yes | App functionality |
| User content: photos | yes (photos sent for a place) | yes | App functionality |
| User content: customer support | yes (problem reports) | yes | App functionality |
| User content: other user content (trips, bookings, documents, expenses, lists) | yes | yes | App functionality |
| Identifiers: user ID | yes | yes | App functionality, analytics |
| Identifiers: device ID (the random device code for counting) | yes | yes | Analytics |
| Usage data: product interaction | yes | yes | Analytics |
| Diagnostics: other diagnostic data (app errors) | yes | yes | App functionality |
| Location, health, financial, contacts, browsing history, purchases | no | | |

A judgment call: what someone doesn't eat may hint at religion, and Apple lists religious beliefs under "Sensitive
info". Toogo asks about food, not about belief, so it is left out here. If Apple's reviewer asks, the answer is
that the questionnaire collects dietary preferences only.
