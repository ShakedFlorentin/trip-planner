## The account note: `docs/<account>-reels-<YYYY-MM-DD>.md`
1. Who the account is (one paragraph).
2. How it was read: frames or captions, signed in or out.
3. Table: shortcode, topic, lesson, frame or caption.
4. Skipped, with reasons.
5. What Toogo should take (ideas needing code are for the owner).
6. Processed shortcodes list.

## Also
- Update the registry table in `toogo-learn-from-reels` (mark "partial: 12 of N" when signed out).
- Add a memory note (type reference) with link, date and doc path, and a line in `MEMORY.md`.
- Do not commit.

## Hand-back to Atlas, per channel
Posts total, captions read, reels watched by frame, skipped with reasons; which craft skills changed and which rules were added; the 5 most useful new lessons; what could not be done (for example frames not readable).

## Style
Terse, phone-readable. Name the creator's numbers as claims. End with what was not checked.

## Craft skill state
On 16 Nov `toogo-marketing-craft` still had an empty Rules section. Check the skill before adding so you do not duplicate.
